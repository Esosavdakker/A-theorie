Actiepunten voor Alex

Wat Alex zelf nog moet doen

1
Contactgegevens invullen
Telefoonnummer, e-mailadres, WhatsApp-link en adres aanpassen in src/config/site.config.js. Nu staan er placeholders.
2
Netlify omgevingsvariabelen instellen
In Netlify → Site configuration → Environment variables: CONTACT_EMAIL (jouw e-mailadres) en EMAIL_API_KEY (Resend API key) invullen zodat het contactformulier werkt.
3
Resend.com account aanmaken
Gratis account op resend.com, domein verifiëren, API key aanmaken en in Netlify plakken. Daarna werkt het contactformulier volledig.
4
Eigen domein koppelen
aplustheorie.nl kopen (bijv. via TransIP of Mijndomein) en koppelen aan Netlify. Netlify regelt SSL (HTTPS) automatisch.
5
OG-afbeelding toevoegen
Een afbeelding van 1200×630px opslaan als public/og-image.jpg voor mooie previews op WhatsApp, Facebook en Google.
